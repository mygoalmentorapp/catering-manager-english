# Catering Manager Pro - English Version Design

This is the English LTR version of the Hebrew "Catering Manager" app. All screens, flows, and features are identical to the Hebrew version but adapted for English-speaking users with left-to-right layout.

## Screen List

| Screen | Description |
|--------|-------------|
| Onboarding | Welcome slides introducing app features |
| Early Access | Beta access screen with feature highlights |
| Login | Email/password sign in |
| Signup | Email/password registration with verification |
| Forgot Password | Password reset via email |
| Email Confirm | Deep link email verification handler |
| Home | Dashboard with business logo, stats, quick actions |
| Orders | Order list with search, filter, archive |
| Order Detail | Full order editor with products, pricing, documents |
| Products | Product catalog with categories, pricing, units |
| Shopping Lists | Generated shopping lists from orders |
| Shopping List View | Read-only shopping list with sharing |
| Shopping List Edit | Editable shopping list with manual items |
| Settings | Business settings, theme, dark mode, tutorials |
| About | App info, version, contact |
| Feedback | User feedback form |
| Video Tutorials | Tutorial video player |
| Changes Review | Review product/order changes |
| Demo Order | Sample order for new users |

## Primary Content and Functionality

Each screen mirrors the Hebrew version exactly, with all text in English and layout flowing left-to-right.

## Key User Flows

1. **Onboarding** -> Early Access -> Login/Signup -> Home
2. **Home** -> Orders -> Create Order -> Add Products -> Save
3. **Orders** -> Select Orders -> Generate Shopping List -> Share via WhatsApp
4. **Settings** -> Upload Logo -> Set Business Name -> Choose Theme Color

## Color Choices

Same as Hebrew version - uses the DS_COLORS design system with customizable primary color.

## Layout Direction

All layouts use LTR (left-to-right) direction, which is the default for English.
